# Jogo Campo Minado 
## Descrição: 
  O objetivo acdêmico da criação desse projeto, tem como principal foco na pratica de construir um código utilizando a lingaguem Java, aperfeiçoando nossos conhecimentos na emplementação de um paradigma Lógico.

## Construção do código
  O projeto foi dividido em 3 classe para a criação do jogo, sendo elas as Campo_minado, Jogo e Tabuleiro
  ```bash
    Tabuleiro.java:
      Sendo a principal que vai gerar os principais atributos, criando o formato, as minas e onde elas estaram espalhadas
    Jogo.java:
      Nessa classe será utilizados metódos para a geração do menu e principais condições para que o jogo continue
    Campo_minado:
      Por fim, será inicializada nessa ultima classe para compilar todos as outras classes
  ```

## Como jogar? 
  Para começar, o tabuleiro será criado de forma linear, possuindo linhas e colunas de 8x8, mantendo o mesmo objetivo do jogo padrão: 
    Localize todas as 10 bombas/minas do tabuleiro e evite tocar nelas.
